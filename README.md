# 🩺 Aditya's Chronicles

> Free study sessions, practice questions & PDF notes for NEET, JEE & CBSE 2027 aspirants.

A modern, lightweight educational platform built with HTML, CSS, JavaScript & Firebase — completely free forever.

🔗 **[Live Website](https://adityaschronicles.vercel.app)**

---

## ✨ Features

- 📚 Chapter-wise notes for Classes 11 & 12 (Biology, Chemistry, Physics)
- 🟢 Interactive HTML sessions (fullscreen iframe)
- 📕 PDF notes for download
- 📝 AI-generated practice questions
- 🎯 NEET · JEE · CBSE focused
- 🆓 100% free · No paywalls
- 📱 Fully responsive

## 🛠️ Setup

1. Clone the repo
2. Add your Firebase config in `index.html`
3. Deploy to Vercel / GitHub Pages

Firestore collection: `files` with fields — `subjectKey`, `chapterIndex`, `fileType`, `name`, `fileContent`, `size`, `uploadedAt`
